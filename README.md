# DockerWard 🛡️

> **Runtime Security Audit & Hardening Tool for Docker Containers**  
> Audits live Docker daemons and inspecting active containers against the CIS Docker Benchmark.

Part of a three-layered infrastructure security portfolio:
1. **Host / OS Layer:** [ArchForge](https://github.com/h3n-x/archforge) — Linux modular automation & hardening.
2. **Code & CI/CD Layer:** [Repo Secret Auditor](https://github.com/h3n-x/repo-secret-auditor) — Secret scanning & SARIF 2.1.0 gate.
3. **Container Runtime Layer:** **DockerWard** (Current) — Linux kernel isolation, namespaces, cgroups v2, and runtime container security auditing.
